# BotNest Frontend

BotNest is a multi-tenant AI SaaS platform designed to convert website visitors into leads through real-time chatbot interactions.

This repository contains the frontend implementation focused on performance, responsiveness, and clean UI architecture.

## Key Features
- Responsive, mobile-first UI across desktop and mobile
- Conversion-focused landing page design
- Reusable frontend components and structure
- Integrated Stripe checkout flow
- Real-time chatbot integration via API

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Stripe API
- Supabase (backend integration)
