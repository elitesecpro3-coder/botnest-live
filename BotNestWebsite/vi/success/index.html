Chào Mừng Đến Với BotNest — 14 Ngày Dùng Thử Đã Bắt Đầu 🎉

Chatbot dùng thử của bạn đã được kích hoạt. Bước tiếp theo là cài đặt trợ lý AI lên website để bắt đầu thu thập khách hàng tiềm năng.

✉ Kiểm tra email ngay bây giờ

Mã nhúng chatbot và hướng dẫn thiết lập đã được gửi đến email bạn đã cung cấp. Thường mất 1–5 phút để nhận được.

Không tìm thấy? Kiểm tra thư mục spam hoặc thư rác và tìm tiêu đề bắt đầu bằng "BotNest đã sẵn sàng".

Đưa Chatbot Lên Website Trong 5 Phút

  1. 1Trong WordPress, vào Giao diện → Trình chỉnh sửa theme, hoặc cài plugin miễn phí Insert Headers and Footers.
  2. 2Mở file footer.php (hoặc mục "Scripts in Footer" nếu dùng plugin).
  3. 3Sao chép thẻ script từ email thiết lập của bạn.
  4. 4Dán vào ngay trước thẻ đóng </body>.
  5. 5Nhấn Cập nhật file. Truy cập website — nút chat sẽ xuất hiện ở góc dưới bên phải.

Dùng Elementor hoặc Divi? Sử dụng cài đặt custom code hoặc footer script tích hợp sẵn của chúng thay vì Trình chỉnh sửa Theme.

  1. 1Trong Wix dashboard, nhấn Cài đặt ở thanh bên trái.
  2. 2Chọn Mã tùy chỉnh (trong mục Nâng cao).
  3. 3Nhấn + Thêm mã tùy chỉnh ở góc trên bên phải.
  4. 4Dán script từ email thiết lập vào ô mã.
  5. 5Đặt Vị trí mã là "Body — cuối", áp dụng cho "Tất cả các trang", rồi nhấn Áp dụng.

Xuất bản lại website sau khi thêm mã để thay đổi có hiệu lực.

  1. 1Trong Squarespace, vào Cài đặt → Nâng cao → Chèn mã.
  2. 2Cuộn xuống trường Footer.
  3. 3Dán script từ email thiết lập vào trường Footer.
  4. 4Nhấn Lưu. Bot sẽ xuất hiện trên mọi trang của website.

Chèn mã yêu cầu gói Business trở lên. Nếu bạn dùng gói Personal, cần nâng cấp để thêm script tùy chỉnh.

  1. 1Trong Shopify admin, vào Cửa hàng trực tuyến → Themes.
  2. 2Nhấn Hành động → Chỉnh sửa mã trên theme đang dùng.
  3. 3Mở file Layout / theme.liquid.
  4. 4Dán script từ email thiết lập ngay trước </body>.
  5. 5Nhấn Lưu. Truy cập cửa hàng để xác nhận nút chat xuất hiện.

Hoạt động trên tất cả các gói Shopify. Thay đổi áp dụng toàn site ngay sau khi lưu.

  1. 1Trong GoDaddy Website Builder, mở trình chỉnh sửa và vào Cài đặt.
  2. 2Tìm Theo dõi & Phân tích hoặc Mã tùy chỉnh / Scripts.
  3. 3Dán script từ email thiết lập vào phần mã tùy chỉnh.
  4. 4Lưu và xuất bản. Nút chat sẽ xuất hiện ở góc dưới bên phải website.

Dùng GoDaddy Managed WordPress? Thực hiện theo hướng dẫn WordPress ở tab phía trên.

  1. 1Mở file HTML website của bạn bằng trình soạn thảo code (Notepad, VS Code, v.v.).
  2. 2Sao chép thẻ script từ email thiết lập.
  3. 3Dán vào mỗi trang ngay trước thẻ đóng </body>.
  4. 4Tải file đã cập nhật lên host qua FTP, cPanel hoặc bảng quản trị hosting.
  5. 5Truy cập website và xác nhận nút chat xuất hiện ở góc dưới bên phải.

Nếu website dùng file layout chung (ví dụ: header.php, layout.html), thêm script vào đó một lần sẽ áp dụng tự động cho tất cả các trang.
