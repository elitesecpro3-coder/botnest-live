Get Your Bot Live in 5 Minutes

  1. 1In your WordPress dashboard, go to Appearance → Theme Editor, or install the free Insert Headers and Footers plugin.
  2. 2Open your footer.php file (or the "Scripts in Footer" section if using the plugin).
  3. 3Copy your embed script from the box above (or from your setup email).
  4. 4Paste it just before the </body> closing tag.
  5. 5Click Update File. Visit your site — the chat button will appear in the bottom-right corner.

Using Elementor or Divi? Use their built-in custom code or footer script settings instead of the Theme Editor.

  1. 1In your Wix dashboard, click Settings in the left sidebar.
  2. 2Select Custom Code (under Advanced).
  3. 3Click + Add Custom Code in the top right.
  4. 4Paste the script from your setup email into the code box.
  5. 5Set Place Code In to "Body — end", apply to "All Pages", then click Apply.

Publish your site after adding the code for the changes to go live.

  1. 1In Squarespace, go to Settings → Advanced → Code Injection.
  2. 2Scroll to the Footer field.
  3. 3Paste the script from your setup email into the Footer field.
  4. 4Click Save. The bot will appear on every page of your site.

Code Injection requires a Business plan or above. If you're on a Personal plan, you'll need to upgrade to add custom scripts.

  1. 1In your Shopify admin, go to Online Store → Themes.
  2. 2Click Actions → Edit Code on your active theme.
  3. 3Open the Layout / theme.liquid file.
  4. 4Paste the script from your setup email just before </body>.
  5. 5Click Save. Visit your store to confirm the chat button appears.

Works on all Shopify plans. Changes apply site-wide immediately after saving.

  1. 1In GoDaddy Website Builder, open your site editor and go to Settings.
  2. 2Look for Tracking & Analytics or Custom Code / Scripts.
  3. 3Paste the script from your setup email into the custom scripts section.
  4. 4Save and publish. The chat button will appear in the bottom-right corner of your site.

Using GoDaddy Managed WordPress? Follow the WordPress instructions in the tab above instead.

  1. 1Open your website's HTML file(s) in a code editor (Notepad, VS Code, etc.).
  2. 2Copy the script tag from your setup email.
  3. 3Paste it on every page just before the closing </body> tag.
  4. 4Upload the updated file(s) to your web host via FTP, cPanel, or your hosting dashboard.
  5. 5Visit your site and confirm the chat button appears in the bottom-right corner.

If your site uses a shared layout file (e.g., header.php, layout.html), adding the script there once will apply it to every page automatically.
